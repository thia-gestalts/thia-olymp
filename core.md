# Olymp

One learner account connects vizint, Gestalter desktop and Gestalter mobile across devices. Sign-in enables automatic end-to-end encrypted replication of the entire personal base. Each fully synced app holds a local copy of all records and attachment bytes, including kinds its own UI never renders. New Thia clients can interoperate by understanding existing gestalts.

The server manages accounts, device sessions and encrypted sync. Clients unlock the base, commit local changes and reconcile them. Keep the sign-up and sign-in experience turnkey, reusing the existing OPAQUE-based flow. Interaktiv is independent.

## Data ownership

Learners can use participating apps locally before choosing to sign in. Keep the active account’s replica clearly scoped to that account. A replica can restore data after a device is lost. Deletions also replicate. Keep the distinction between a complete replica and retained history visible in recovery and status wording.
